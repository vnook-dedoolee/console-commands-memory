# 📘 Памятка по консольным командам

## 🐧 Linux

| Команда                                             | Описание                                                  |
|:----------------------------------------------------|:----------------------------------------------------------|
| `pwd`                                               | Показывает текущую рабочую директорию.                    |
| `ls`                                                | Выводит список файлов и папок в директории.               |
| `cd <folder>`                                       | Перемещает вас в указанную папку.                         |
| `mkdir <name>`                                      | Создает новую директорию.                                 |
| `rm <file>`                                         | Удаляет файл.                                             |
| `cp <source> <dest>`                                | Копирует файл или папку.                                  |
| `mv <source> <dest>`                                | Перемещает или переименовывает элемент.                   |
| `cat <file>`                                        | Выводит содержимое файла в терминал.                      |
| `grep <pattern> <file>`                             | Ищет строки, соответствующие шаблону.                     |
| `chmod`                                             | Изменяет права доступа к файлу.                           |
| `java -jar ************ > <path>/output.log 2>&1 &` | Запускает JAR-файл в фоновом режиме на Linux-сервере.     |
| `scp <path> <domain>:<path>`                        | Копирование файла с локальной машины на удаленный сервер. |
| `ps aux ║ grep java`                                | Показывает запущенные java-процессы.                      |
| `ssh <domain>`                                      | Подключение к серверу по ssh.                             |

## 🐙 Git

Понял, оставляю твою структуру. Вот исправленная таблица:

| Команда                                                  | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|:---------------------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `git init`                                               | Инициализирует новый Git-репозиторий в текущей папке.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `git clone <url>`                                        | Клонирует удаленный репозиторий на ваш компьютер.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `git status`                                             | Показывает текущее состояние файлов (изменения, добавления).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `git add <file>`                                         | Добавляет файл в область подготовленных изменений (staging area).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `git commit -m "msg"`                                    | Фиксирует изменения с комментарием.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `git push`                                               | Отправляет локальные коммиты в удаленный репозиторий.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `git pull`                                               | Забирает изменения из удаленного репозитория и сливает их с вашими.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `git branch`                                             | Показывает список веток.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `git checkout <branch>`                                  | Переключается на другую ветку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `git log`                                                | Показывает историю коммитов.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `git merge <branch>`                                     | Вливает указанную ветку в текущую.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `git checkout --ours <file>`                             | `--ours` при конфликте — оставить СВОЮ версию файла.<br/>`--theirs` — оставить ЧУЖУЮ версию файла.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `git remote add origin <url>`                            | Привязка локального репозитория к удалённому.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `git cherry-pick <hash-commit>`                          | Взять конкретный коммит из одной ветки и применить его в другой.<br/>`-n`, `--no-commit` — применить изменения без создания коммита.<br/>`-e`, `--edit` — редактировать сообщение коммита.<br/>`-x` — добавить ссылку на исходный коммит.<br/>`--continue` — продолжить после разрешения конфликтов.<br/>`--skip` — пропустить текущий коммит при конфликте.<br/>`--abort` — отменить черри-пик и вернуться к исходному состоянию.                                                                                                                                               |
| `git lfs install`                                        | Установка Git Large File Storage (LFS). Git LFS заменяет большие файлы на текстовые указатели внутри Git, а содержимое файлов хранит на отдельном сервере. Это позволяет обойти ограничения GitHub по размеру файлов.                                                                                                                                                                                                                                                                                                                                                            |
| `git lfs track <filename.type>`                          | Указывает Git LFS, какие типы файлов отслеживать (заменять на указатели). Например: `git lfs track "*.pth"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `git add .gitattributes`                                 | Делает файл `.gitattributes` готовым к коммиту. В `.gitattributes` лежат правила, как Git должен обрабатывать файлы (например, какие файлы отдавать под LFS).                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `git lfs migrate import --include="<path>" --everything` | Переписывает историю коммитов, переводя указанный файл под LFS задним числом.<br/>- `migrate import` — переделать старые коммиты.<br/>- `--include="путь"` — указать конкретный файл.<br/>- `--everything` — обработать все коммиты от начала до конца.<br/><br/>**Когда нужен:**<br/>- Файл уже закоммичен до настройки LFS.<br/>- `git push` падает с ошибкой про большой файл.<br/>- `git lfs ls-files` не показывает файл.<br/><br/>**Когда НЕ нужен:**<br/>- Файл ещё не закоммичен.<br/>- Файл добавлен после настройки LFS.<br/>- `git lfs ls-files` уже показывает файл. |
| `git config --global user.name "<git_name>"`             | Настроить имя пользователя для всех репозиториев. Если убрать `--global`, то только для текущего проекта.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `git config --global user.email "<git_email>"`           | Настроить почту пользователя для всех репозиториев. Если убрать `--global`, то только для текущего проекта.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `git push --force-with-lease origin <branch>`           | Полностью заменить удаленную ветку своими локальными изменениями                                                                                                                                                                                                                                                                                  |

## 💻 Windows

| Команда                                                              | Описание                                                        |
|:---------------------------------------------------------------------|:----------------------------------------------------------------|
| `java -XshowSettings:properties -version 2>&1 ║ findstr "java.home"` | Показывает, где лежит java.                                     |
| `netsh wlan show networks mode=bssid`                                | Показывает все доступные Wi-Fi сети в режиме подробного вывода. |
| `netsh wlan show profiles`                                           | Показывает профили, к которым было подключение.                 |
| `netsh wlan show profiles`                                           | Показывает профили, к которым было подключение.                 |
| `netsh wlan delete profile name="<profile_name>"`                    | Удалить определённый профиль Wi-Fi.                             |
