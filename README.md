# 📘 Памятка по консольным командам

## 🐧 Linux (Основные команды)

| Команда                                             | Описание                                                  |
|:----------------------------------------------------|:----------------------------------------------------------|
| `pwd`                                               | Показывает текущую рабочую директорию.                    |
| `ls`                                                | Выводит список файлов и папок в директории.               |
| `cd <folder>`                                       | Перемещает вас в указанную папку.                         |
| `mkdir <name>`                                      | Создает новую директорию.                                 |
| `rm <file>`                                         | Удаляет файл.                                             |
| `cp <source> <dest>`                                | Копирует файл или папку.                                  |
| `mv <source> <dest>`                                | Перемещает или переименовывает элемент.                   |
| `cat <file>`                                        | Выводит содержимое файла в терминал.                      |
| `grep <pattern> <file>`                             | Ищет строки, соответствующие шаблону.                     |
| `chmod`                                             | Изменяет права доступа к файлу.                           |
| `java -jar ************ > <path>/output.log 2>&1 &` | Запускает JAR-файл в фоновом режиме на Linux-сервере.     |
| `scp <path> <domain>:<path>`                        | Копирование файла с локальной машины на удаленный сервер. |
| `ps aux ║ grep java`                                | Показывает запущенные java-процессы.                      |
| `ssh <domain>`                                      | Подключение к серверу по ssh.                             |

## 🐙 Git (Основные команды)

| Команда                       | Описание                                                                                                                                    |
|:------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------|
| `git init`                    | Инициализирует новый Git-репозиторий в текущей папке.                                                                                       |
| `git clone <url>`             | Клонирует удаленный репозиторий на ваш компьютер.                                                                                           |
| `git status`                  | Показывает текущее состояние файлов (изменения, добавления).                                                                                |
| `git add <file>`              | Добавляет файл в область подготовленных изменений (staging area).                                                                           |
| `git commit -m "msg"`         | Фиксирует изменения с комментарием.                                                                                                         |
| `git push`                    | Отправляет локальные коммиты в удаленный репозиторий.                                                                                       |
| `git pull`                    | Забирает изменения из удаленного репозитория и сливает их с вашими.                                                                         |
| `git branch`                  | Показывает список веток.                                                                                                                    |
| `git checkout <branch>`       | Переключается на другую ветку.                                                                                                              |
| `git log`                     | Показывает историю коммитов.                                                                                                                |
| `git checkout --ours <file>`  | --ours при rebase — это ВАШИ изменения (то, что было в вашей ветке до rebase)<br/>--theirs — это чужие изменения из ветки, например develop |
| `git remote add origin <url>` | Привязка проекта к удалённому репозиторию                                                                                                   |
